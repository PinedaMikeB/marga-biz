# AI Visibility Reports

Run `npm run ai:visibility` after content changes or after a production deploy. The report checks whether priority printer-rental pages have answer-engine summary blocks, FAQ/question signals, canonical tags, JSON-LD, and AI-search-friendly robots rules.

The manual prompt matrix in `latest.md` is for spot-checking ChatGPT, Gemini, Claude, and Perplexity because those systems do not expose stable ranking data the way Search Console does.

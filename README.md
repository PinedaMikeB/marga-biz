## 🚀 Quick Start

### Local Development

```bash
# Install dependencies
npm install

# Generate pages from WordPress data
npm run generate

# Start local server
npm run serve

# Open browser
open http://localhost:8080
```

### Deploy to Netlify

```bash
# Initialize git (first time only)
git init
git add .
git commit -m "Initial commit"

# Connect to GitHub
gh repo create marga-biz --public --source=. --remote=origin --push

# Netlify will auto-deploy when you push to main
```
